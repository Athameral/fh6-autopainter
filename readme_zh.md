# FH6-AutoPainter

> 利用图形图元（shapes）近似拟合任意图像，并将其导入到《极限竞速：地平线 6》中。

[English Documentation](README.md)

---

## 💡 关于项目

**FH6-AutoPainter** 是一款轻量级实用工具，旨在解决《极限竞速：地平线》系列游戏无法直接导入外部 PNG 贴图的限制。通过将目标图像转换为优化后的几何图元，本工具能够实现自动化创作流程，让你轻松将自定义画作带入游戏中。

---

## ✨ 核心优势

- **单文件便携式程序**：零繁琐安装，即下载即用。
- **极小体积**：经过 UPX 压缩后仅约 3MB，完全自包含（无需额外依赖）。
- **跨 GPU 平台兼容**：支持任何兼容 **Vulkan** 的硬件，无需担心 GPU 品牌限制。

## 🚀 使用说明

1. 从 Release 页面下载最新的预编译程序 `FH6-AutoPainter.exe`。
2. 启动应用程序。
3. **拖入** 你的目标图像（支持 PNG/JPG 格式）。
4. 根据个人喜好配置图元数量（number of shapes）及其他参数。**请确保所有涉及“图元数量”的参数设置保持一致。**
5. 按照游戏内注入提示，将其加载导入至《极限竞速：地平线 6》中。

## 🛠️ 构建说明

如果你更倾向于从源码编译本项目，请参考以下步骤：

### 环境要求
- 现代 C++ 编译器工具链（例如 `llvm-mingw` 或 MSVC）
- CMake（3.20 或更高版本）
- Git

> 注意：MSVC 是 `taichi` 在 Windows 平台上默认使用的编译器，通常可以直接工作（未经测试）。不过，为了确保项目可以在不额外下载其他依赖项的情况下顺利构建，推荐使用 `llvm-mingw` 作为编译器工具链。
